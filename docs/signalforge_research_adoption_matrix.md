# SignalForge Research Adoption Matrix — Mature Research A2

## Hard rule
SignalForge does not invent a new algorithm where a mature research/industry method already exists. Mature components are COPY/ADAPT engineering. Only unresolved opportunity-intelligence questions remain RESEARCH.

## Mature methods now adopted

| Subsystem | Status | SignalForge A2 implementation | What is no longer allowed |

| Need / complaint extraction | COPY/ADAPT | Partial evidence atoms; missing actor/scope/signature is incomplete evidence, not deletion | `PRIMARY_SIGNATURE_MISSING -> DEAD` |

| Problem-family clustering | COPY/ADAPT | retrieve → rerank → representative anti-bridge check | global all-cluster scan or exact-signature-only join |

## A2 live acceptance target
A2 is not successful merely because code tests pass. On real data it must make the evidence funnel observable:

1. Signature-missing firsthand need fragments survive.
2. Balanced retrieval has broad anchor coverage rather than global-bucket starvation.
3. True recurring pains can form independent multi-evidence problem families while same-product different-pain cases remain separate.
4. Low-information metadata/code fragments fall into retained MISC, not scarce Research/Recovery.
5. Recovery selects targetable, diversified evidence gaps and never sends metadata-shaped queries.
6. Supply / market-state objects can exist without being misread as WTP.
7. If multi-evidence remains zero, the audit prints retrieval relation telemetry and related-pair samples; the system must report BLOCKED rather than self-certify usability.

## Frontier truth boundary
A2 remains a research-grounded evidence/problem-family engine. It does not automatically claim that a problem family is a venture opportunity, that an external change proves "why now", that a founder can capture it, or that a buyer will pay. Those require the frontier modules and external outcomes.
