# SignalForge Founder-Usable U7

U7 is a convergence cut built on U6. It keeps U6 memory-bounded persistence and adds:

- schema-only feedback-role migration on U6 cache hits (no parser full reparse);
- maker-promo vs user-self-solution vs workaround separation;
- narrow technical self-solutions filtered from Founder attention unless broader workflow evidence exists;
- canonical corpus append-only recovery (source-cache subset may never replace the full corpus);
- a reserved recovery slot for the strongest observed user self-solution;
- balanced recovery quota so market-supply context is actually queried;
- market/supply context linked to user-innovation cards as context only, never WTP;
- U6 five-card live regression fixtures treated as product acceptance.

Truth boundary: cards are research/discussion inputs, not venture recommendations or market validation.
