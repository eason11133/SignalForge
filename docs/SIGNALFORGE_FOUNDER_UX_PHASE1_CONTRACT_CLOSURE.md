# SignalForge Founder UX Architecture v1 — Phase 1 Founder Contract Closure

Scope is intentionally narrow. No React redesign and no Phase 2 App Shell work.

## Closed contracts

1. **Canonical lineage** — Part 1 `MATCHED` means compatible Published evidence only. Truth inheritance requires stable `published_thesis_id`, `problem_lineage_id`, and `canonical_binding_id` with canonical-lineage status.
2. **One Opportunity home** — source-object identity is separate from canonical Opportunity identity. A canonically matched Founder hypothesis resolves to the Published thesis Opportunity and survives as an alias/source identity.
3. **Owner != attention** — PARK / DO_NOT_INVEST_NOW do not become recurring Founder Inbox work merely because owner is FOUNDER.
4. **Attention priority** — Today is sorted by canonical attention priority and attention event identity, never input order.
5. **Founder language boundary** — known backend English prose/status enums are translated or fail closed to natural Chinese fallback in Founder ViewModels.
6. **ChatGPT snapshot contract** — `published_thesis_id`, `published_snapshot_id`, and `published_revision` are distinct. Missing immutable snapshot identity remains null.
7. **Eason One reservation** — future handoff schema reserves `why`, `deliverable`, `deadline`, `must_verify`, `constraints`, `source_opportunity_id`, and `source_market_test_id` while runtime remains unavailable.
