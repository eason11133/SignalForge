# SignalForge Live Intelligence Semantic Closure

Scope: narrow closure only. No new Part, no Phase 2, no React redesign.

## A. Source-fit adequacy now depends on actual configured source families

`SOURCE_FIT_SUFFICIENT` is no longer inferred from a coarse source profile alone.
The router now separates:

- transport completion
- configured source-set completion
- actual observation-domain source fit

Each source profile declares observation-source families and a minimum family match.
A Founder hypothesis can be PARKed on zero traces only when the source set is complete **and** the actually configured source families cover the buyer/problem observation domain.

Exact live closure case:

`Productized LINE Bot / Workflow Automation for Small Nonprofits`

with only HN / Stack Overflow / GitHub Issues / GitHub Repositories now resolves to:

- source profile: `NONPROFIT_OPERATIONS`
- source set: complete
- source fit: insufficient
- disposition: `WAIT_FOR_SOURCE_FIT`

No market-absence conclusion is allowed.

## B. Fresh traces must pass thesis relevance before counters

The fast-probe pipeline is now:

`search hit -> thesis relevance -> problem-role classification -> trace counter`

A trace is countable only if deterministic semantic compatibility is established across sufficient dimensions such as actor, job/workflow, context/domain, and distinctive problem terms.

Keyword overlap alone is insufficient.

Non-countable traces remain inspectable as `IRRELEVANT` or `INSUFFICIENT_RELEVANCE`, but cannot change:

- problem discussions
- firsthand pain
- workarounds
- paid signals
- spend observations
- paid dissatisfaction
- Decision Frontier

Exact live closure case:

`English Output Trainer for Taiwan Exam Students`

The following unrelated GitHub-like hits must contribute zero substantive traces:

- GPTsHunter submission
- redditgifts tracking
- Facebook LAMA vocabulary bug

A positive control with Taiwan exam students + English writing/translation remains countable.

## Truth boundary

- source-fit is routing metadata only
- fresh trace relevance remains `UNVALIDATED_SEARCH_TRACE`
- no C01-C14 write
- no Market Truth write
- no recurrence promotion
- no Published thesis disposition mutation
