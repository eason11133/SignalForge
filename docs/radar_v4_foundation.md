# Radar V4.0 — Evidence-Governed Foundation

## Purpose
V4.0 changes the unit of truth from `candidate + score` to:
`case + atomic claims + evidence ledger + unknowns + assumptions + decision history`.

Legacy scores/stages are preserved as context only. They do not become V4 truth.

## Claim states
UNKNOWN / INSUFFICIENT / SUPPORTED / REFUTED / CONFLICTED

## Evidence stances
SUPPORT / REFUTE / INSUFFICIENT / RELATED

## Conservative migration
- raw community problem -> C01 support
- concrete actor -> C04 support
- consequence/workaround -> insufficient, not proof
- verified direct_problem_corroboration -> C02 support
- jobs/buyer signals -> insufficient for willingness-to-pay
- solution/competitor activity -> related/insufficient, not proof of a gap
- timing/context -> insufficient for durability

## Initial verdict
- C01 refuted -> IGNORE
- C02 supported by >=2 independent direct source families -> INVESTIGATE
- otherwise -> WATCH

V4.0 never creates VALIDATE or BUILD.

## Non-goals
No LLM calls.
No UI changes.
No deletion of existing candidate data.
No Solution Landscape, Build Reality, Distribution or Race conclusions yet.
