# SignalForge Founder-Usable U8

U8 adopts mature Web Need-Solution Pair and user-innovation diffusion concepts as production research infrastructure.

- A self-built project is **not** automatically User Innovation.
- `SELF_SOLUTION_FOR_OWN_NEED` requires a causal/local own-need + self-solution pair.
- Showcases, founder/vendor promotion, ordinary workaround use, and discussion/opinion are separate source intents.
- Need recurrence search and solution/supply search use separate queries.
- A user innovation may become a `DIFFUSION_OR_COMMERCIALIZATION_GAP_RESEARCH_CANDIDATE`, but that status is never treated as proven until independent recurrence and diffusion/adoption evidence exist.
- Source dependence, market supply != WTP, zero Current, and external-outcome validation boundaries remain unchanged.
