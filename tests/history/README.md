# Historical verification evidence

This directory preserves older SignalForge acceptance, regression, smoke, replay and benchmark scripts.

They are retained to show engineering evolution and regression evidence, but they are **not** the canonical current test surface. Some scripts intentionally preserve historical assumptions about the repository root or old runtime generations.

Current representative checks remain at repository root because existing runtime/import/path contracts depend on that location. See [Repository Audit](../../docs/REPOSITORY_AUDIT.md).
